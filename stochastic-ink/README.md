# Stochastic Ink — v.08

Audio-gated bounded filament field. Blank until a playing track produces an audible signal; holds on silence, pause and end. The GPU samples up to 524,288 points along deterministic, continuously deforming cubic path families, plus up to 1,600 connected line families. No outward velocity integration, respawning or accumulating positions. Smooth tanh projection bounds every vertex inside 94% of the clip-space half extents. Bass changes expansion, mids alter curvature and fine structure, transient energy drives accents, highs change particle detail. FFT band envelopes are normalised with decaying peak references. Motion echo is bounded and optional. The audio and recording paths remain local. All versions v.01–v.07 are playable archives, including exact v.07 source. This is a procedural interpretation, not a reconstruction of the reference footage. Requires WebGL2; no float render-target extension needed.
