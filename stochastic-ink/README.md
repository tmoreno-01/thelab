# Stochastic Ink — v.10

Persistent GPU particle advection via WebGL2 transform feedback. Each particle stores position, velocity, age, lifetime and generation. Twelve slowly evolving source jets, five local eddies per group and multi-scale shear are driven by individually filtered bass, mid, high and onset signals. The audio changes velocity targets rather than directly changing vertex positions. Fixed 60 Hz integration, inertial response, lifespan fade/re-emission, aspect-aware containment, three ink populations and adjustable trail persistence. Waits for audible playback; holds on silence/pause. This is a procedural velocity-field system, not a pressure-projection Navier–Stokes solver. All v.01–v.09 versions remain archived.
